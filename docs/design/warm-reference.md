# Warm desktop direction: verified reference packet

## User decision and precedence

The user explicitly asked for a striking, warm, modern, playful/fantastical interface, requested real reference research, and named CleanMyMac as the craft reference. This replaces the former Space Layers slate/teal/ochre aesthetic. It changes visual design, not Reclaim's four-section product, data integrity, scan consent or cleanup protections.

This user-pinned reference supersedes earlier generic bans on gradients, rounded task surfaces, dimensional artwork and expressive color. Keep useful Operate-mode structure and accessible familiar controls; do not flatten the reference into a cold admin template.

## Reclaim translation

**Character:** warm and imaginative, polished enough to feel like a crafted macOS product. Rich plum navigation and shadow, lilac/berry atmosphere, peach/coral highlights and creamy warm-light surfaces. Dark mode remains warm plum rather than blue-black. Preserve real contrast; imagery and subtle gradients cannot be the background behind unreadable small text.

**First viewport:** familiar left navigation and titlebar-safe shell; an inviting contextual surface with a single original folder/storage sculpture and a real next action; clear scan/volume/coverage state. Measured sessions then show their usage strip and ranked paths/categories within the same world. No invented sample metrics in production and no giant promotional hero that pushes the job offscreen.

**Inspection:** Explore and Development retain crisp comparable rows, a clear filter toolbar and a warm framed inspector. Friendly color/depth should survive dense work without turning each filename into a decorative card. The four sections and shared settings remain discoverable by text labels and coherent icons.

**Motion:** coordinated navigation indicator, controlled inspector entrance, tactile button response, selected category/row continuity and a small authored artwork entrance. Repeated interactions interrupt rather than queue. No spinning theatre, fabricated scan percentage or confetti for deleting data. Reduced motion retains an equally designed static state.

**Identity:** use Reclaim's own original art. The supplied folder/storage sculpture provides a recognizable warm focal object; do not recreate MacPaw's shields, mascots or module objects. Small interface icons remain one coherent vector family with optional warm dimensional holders at genuine hierarchy points.
